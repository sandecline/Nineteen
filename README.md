# 逃离十九层

此仓库按原项目文件夹的目录层级保存游戏工程、素材、截图和项目资料。

- `Nineteen/Nineteen/`：Cocos Creator 3.8.8 工程。使用 Cocos Creator 打开这个目录。
- `素材/`：项目原始图片素材。
- 根目录的图片、Word、PDF 和 PPTX：演示截图与项目资料。成员介绍 PPTX 中的手机号已在上传副本中遮蔽。

Git 不收录可重新生成的 `.git` 历史、`library`、`temp`、`profiles`、`node_modules` 等本地缓存与依赖目录。工程依赖可按对应扩展的 `package.json` 在本地安装。
